# Backend

Planned home of the FairBuy **NestJS API**, hosted on **Render**.

The backend will authenticate users through Supabase, orchestrate comparisons and source connectors, call service-side audio and AI integrations, and access Supabase Postgres.

This directory is a placeholder, not a working application. No deployment is configured yet.

When implementing, configure CORS for the GitHub Pages frontend and keep provider credentials and privileged database keys in server-side environment configuration. Any separate Python audio service remains a deployment decision.
