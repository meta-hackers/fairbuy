# Frontend

Planned home of the FairBuy PWA, with static hosting on **GitHub Pages**.

The frontend will provide text and audio input, editable transcripts, and offer comparisons. It will call the NestJS backend hosted on Render. Speech processing remains service-side.

This directory is a placeholder, not a working application. No deployment is configured yet.

When implementing, account for the GitHub Pages repository base path, client-side navigation, and the public backend URL. Never include provider keys or privileged credentials in the frontend.
